# Sistema de Adquisición de Datos con Excel

## Descripción

Sistema de adquisición de datos desarrollado con Arduino para el monitoreo de temperatura y humedad ambiental. El proyecto permite capturar mediciones mediante un sensor DHT11 y transferir automáticamente la información a Microsoft Excel para su visualización, almacenamiento y análisis en tiempo real.

## Archivos del Proyecto

* `codigo.ino` - Programa principal para adquisición y registro de datos.

## Componentes Utilizados

* Arduino
* Sensor de temperatura y humedad DHT11
* Computador con Microsoft Excel
* Comunicación USB/Serial

## Funcionalidad

* Medición de temperatura ambiente.
* Medición de humedad relativa.
* Transferencia automática de datos a Microsoft Excel.
* Registro cronológico de mediciones.
* Almacenamiento histórico de datos.
* Actualización de variables en tiempo real.
* Generación de tablas para análisis posterior.

## Tecnologías Utilizadas

* Arduino IDE
* C++
* Microsoft Excel
* Arduino Excel 3.0
* Comunicación Serial
* Adquisición de Datos

## Objetivo del Proyecto

Desarrollar una plataforma de adquisición de datos de bajo costo capaz de monitorear variables ambientales y registrar automáticamente las mediciones en Microsoft Excel, facilitando el análisis y seguimiento de la información recolectada.
