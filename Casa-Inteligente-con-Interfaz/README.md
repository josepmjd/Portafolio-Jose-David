# Casa Inteligente con Interfaz

## Descripción

Sistema de domótica y monitoreo residencial desarrollado con un microcontrolador PIC16 y una aplicación de escritorio en C#. El sistema permite supervisar variables ambientales y eléctricas de una vivienda, controlar dispositivos conectados y almacenar registros históricos para su posterior análisis.

## Archivos del Proyecto

* `codigo.c` - Código del microcontrolador PIC16.
* `codigo.cs` - Aplicación de escritorio desarrollada en C#.

## Componentes Utilizados

* Microcontrolador PIC16
* Conversor RS232/USB
* Relés y actuadores
* Sensor de temperatura y humedad DHT11
* Sensores de corriente
* Sensores de voltaje
* Computador con aplicación de monitoreo

## Funcionalidad

* Control de iluminación y dispositivos conectados.
* Monitoreo de temperatura y humedad ambiental.
* Medición de corriente y voltaje.
* Estimación y seguimiento del consumo eléctrico.
* Visualización de variables en tiempo real mediante interfaz gráfica.
* Comunicación serial entre el sistema embebido y la aplicación de escritorio.
* Registro y almacenamiento de datos en archivos CSV.
* Consulta de información histórica.

## Tecnologías Utilizadas

* PIC16
* C
* C#
* Windows Forms
* Comunicación Serial RS232
* CSV para almacenamiento de datos

## Objetivo del Proyecto

Desarrollar una plataforma de automatización residencial capaz de supervisar variables ambientales y eléctricas, controlar dispositivos conectados y mantener un registro histórico de los datos recolectados para facilitar el monitoreo y la gestión energética.
