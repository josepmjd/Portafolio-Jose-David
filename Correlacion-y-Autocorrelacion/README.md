# Correlación y Autocorrelación

## Descripción

Proyecto de procesamiento digital de señales desarrollado en Arduino para el cálculo de correlación cruzada y autocorrelación. El sistema permite analizar la similitud entre señales discretas, evaluar retardos temporales y visualizar los resultados mediante comunicación serial.

## Archivos del Proyecto

* `codigo.ino` - Programa principal para cálculo y análisis de correlación.

## Componentes Utilizados

* Arduino
* Pulsador
* LED indicador
* Computador para monitoreo serial

## Funcionalidad

* Implementación de correlación cruzada entre dos señales discretas.
* Implementación de autocorrelación de una señal.
* Cambio de modo mediante pulsador.
* Indicación visual del modo seleccionado mediante LED.
* Cálculo de correlación para retardos positivos y negativos.
* Transmisión de resultados mediante puerto serial.
* Análisis de similitud entre señales.

## Tecnologías Utilizadas

* Arduino IDE
* C++
* Procesamiento Digital de Señales (DSP)
* Comunicación Serial
* Análisis de Señales

## Objetivo del Proyecto

Implementar algoritmos de correlación cruzada y autocorrelación en una plataforma embebida para estudiar técnicas fundamentales de procesamiento digital de señales, utilizadas en aplicaciones de análisis, detección de patrones y comparación de señales.
