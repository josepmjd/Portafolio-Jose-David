# Servoválvula

## Descripción

Sistema de control para una servoválvula de fabricación propia desarrollado con Arduino. El proyecto permite automatizar la apertura y cierre de una válvula mediante un motorreductor y sensores de posición, proporcionando control sobre el flujo de un fluido y supervisión del estado del mecanismo.

## Archivos del Proyecto

* `codigo.ino` - Programa principal de control y supervisión.

## Componentes Utilizados

* Arduino
* Válvula o registro adaptado
* Motorreductor
* Sensores de posición
* Fuente de alimentación
* Elementos mecánicos de transmisión

## Funcionalidad

* Apertura y cierre automatizado de la válvula.
* Control del motorreductor para posicionamiento del mecanismo.
* Monitoreo de la posición mediante sensores de realimentación.
* Detección de límites de recorrido.
* Supervisión del estado de operación del sistema.
* Automatización del control de flujo.

## Tecnologías Utilizadas

* Arduino IDE
* C++
* Sensores de posición
* Control de actuadores
* Automatización de procesos

## Objetivo del Proyecto

Desarrollar una servoválvula de bajo costo mediante la adaptación de una válvula convencional, integrando control electrónico y realimentación de posición para automatizar la regulación de flujo en aplicaciones de ingeniería y automatización.
